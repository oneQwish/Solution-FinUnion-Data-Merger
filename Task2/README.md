Ключевые решения:

- MDM ведёт клиентов и справочники. Клиентов он сначала сопоставляет и выдаёт единый идентификатор, к 12 месяцам становится мастером. Справочники в MDM с первого этапа; системы RetailBank до вывода меняют свои копии справочников только вслед за MDM.
- Счета, договоры, операции, платежи, карты и кредиты остаются в профильных банковских системах. Новые счета и продукты открываются в системах FinUnion, старые счета RetailBank переносятся волнами.
- RetailBank подключается к Integration Layer через CDC, без доработки систем, которые выводятся в течение года. Обратно в системы RetailBank из MDM ничего не передаётся: соответствие их идентификаторов глобальным хранится в MDM.
- DWH FinUnion получает исходные данные обоих банков через CDC и Kafka, а не готовые витрины RetailBank, и считает метрики по правилам FinUnion.
- Data Steward для всех сущностей — Data Office; владельцы — Data Office и бизнес-направления по структуре компании.
