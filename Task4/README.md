Ключевые решения:

- Клиенты RetailBank переходят в FU CRM после присоединения, волнами по группам клиентов вместе со всеми своими продуктами: клиента обслуживают в той CRM, где ведутся его продукты. После последней волны выводятся RB CRM, RB Cards и RB Loans, RB Core — последним.
- Договоры, счета, карты и кредиты RetailBank переносятся только после присоединения, когда FinUnion становится правопреемником.
- Для cutover выбраны клиентские данные: это главная проблема кейса — дубли клиентов.
