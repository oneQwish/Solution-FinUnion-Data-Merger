# Образ целевого результата через 12 месяцев

| Вопрос | Что меняется |
|---|---|
| Какие системы остаются | FU Core, FU CRM, FU Cards, FU Loans, ESB FinUnion, DWH FinUnion на PostgreSQL, BI FinUnion; новые компоненты — MDM Customer Hub, Kafka и CDC, Data Lakehouse на основе Data Lake FinUnion, Airflow, dbt, DataHub |
| Какие выводятся из эксплуатации | RB CRM, RB Core, RB Cards, RB Loans, RB DWH, RB BI, point-to-point-интеграции RetailBank |
| Какие данные мигрируются | Клиенты RetailBank — в MDM (золотая запись) и FU CRM; согласия на обработку ПДн с документами — в FU CRM; договоры, счета с остатками и действующие платежи — в FU Core; карты — в FU Cards; кредиты со счетами и графиками — в FU Loans; история операций обоих банков — в Lakehouse; данные выведенных систем RetailBank — в архив в объектном хранилище |
| Какие потоки переключаются | Клиентские данные: мастер — MDM вместо двух CRM; справочники: мастер — MDM; финансовые данные RetailBank: из CDC систем RetailBank — на CDC систем FinUnion после переноса; регуляторная отчётность RetailBank: из RB DWH — в единую отчётность DWH FinUnion после присоединения; point-to-point RetailBank — на Integration Layer |
| Какие критерии подтверждают завершение перехода | У каждого клиента один глобальный идентификатор, клиентов без глобального ID не больше 1% (карточка качества клиента); все действующие счета, карты и кредиты RetailBank перенесены, остатки и задолженность сверены до копейки; регуляторная и управленческая отчётность формируется только из DWH FinUnion; системы RetailBank отключены, их данные в архиве; для витрин DWH в DataHub есть lineage до источника и владелец |
